---

## Audience

This is a **beginner** session in the "AI for All" workshop. It is written for
researchers and graduate students who are new to calling a large language model
(LLM) through an API — not for anyone who already works with the `openai` SDK
daily.

## What you already have

- **Basic Python** — you can run a script, a variable, a `for` loop, and an
  `if` statement without help. If you can open a Jupyter notebook and run a
  cell, you can follow this lesson.
- **A web browser** — most of the lesson runs in a notebook you open in a
  browser, either on the Anvil cluster or on your own machine.
- **An API key** — you will be issued (or create) a key for ASU Research
  Computing's OpenAI-compatible gateway. The [Setup](setup.md) page walks you
  through it.

## What you do *not* need

- No prior machine-learning, NLP, or deep-learning background.
- No cloud, DevOps, or networking knowledge.
- Nothing to install if you work on Anvil (we provide a pre-built notebook).

## What you will leave with

- The confidence to **make your first LLM API call** and read the result.
- A small, working **research tool** that batches a set of abstracts through
  the model and returns structured JSON.
- A vocabulary for the next lesson (prompts, tokens, structured output,
  rate limits) so the rest of the workshop makes sense.
